# EAK International School — Frontend Assignment

A responsive, multi-page concept website for the fictional EAK International School, built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home page with hero, school highlights, academics, facilities, sample news, events and footer
- `about.html` — School story, vision, mission, values and principal's message
- `academics.html` — School stages, teaching approach and co-curricular activities
- `admissions.html` — Admission steps, sample document checklist, FAQs and frontend-only enquiry form
- `events.html` — Sample notices/events with working search and category filters

## Run locally
1. Extract the ZIP folder.
2. Open the `eak-international-school` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code extension **Live Server** and choose **Open with Live Server**.

No backend, database or API is used. The enquiry form is a frontend demo and does not send or store information.

## Tech used
HTML5, CSS3, responsive media queries, vanilla JavaScript, Google Fonts and remote Unsplash images.

This is a student assignment prototype. All school details, achievements, events, testimonials, contact information and principal profile are illustrative and are not real institutional claims.
